Sobre o projeto

Uma solução acadêmica voltada à análise prática do setor solar.

O projeto InfoEnergy foi criado para transformar bases energéticas em informações visuais e úteis. A proposta atende principalmente profissionais e empresas que atuam com energia solar e precisam localizar regiões com maior concentração de sistemas fotovoltaicos, possíveis clientes com painéis antigos e oportunidades para serviços de manutenção, limpeza e renovação.

Problema identificado

Dados existem, mas nem sempre estão prontos para apoiar decisões.

A persona do projeto depende de dados para decidir onde atuar, mas muitas informações ficam dispersas, técnicas ou difíceis de interpretar sem tratamento prévio.

01

Dados dispersos

Informações de geração, regiões e crescimento solar ficam em fontes diferentes, dificultando uma visão única do mercado.

02

Dificuldade de prospecção

Profissionais de painéis solares muitas vezes dependem de indicação ou experiência prática para encontrar clientes.

03

Baixa visualização

Planilhas e bases brutas dificultam enxergar regiões líderes, tendências e áreas com maior potencial de atuação.

Solução

Dashboard em Java com filtros, indicadores e visualizações energéticas.

O InfoEnergy centraliza a consulta de dados em uma interface clara, permitindo visualizar indicadores por estado, região, fonte energética e período. O sistema foi estruturado com banco de dados SQL Server e classes de controle para organizar as regras de negócio.

  • Identificação de regiões com maior potencial solar.
  • Comparação entre estados e fontes energéticas.
  • Consulta de dados por filtros selecionados pelo usuário.
  • Geração de gráficos e rankings para tomada de decisão.

Funcionalidades

Recursos principais do MVP

O escopo inicial prioriza as funcionalidades essenciais para transformar dados em análise visual.

📊

Dashboard energética

Apresenta indicadores principais, gráficos e informações resumidas sobre geração e concentração de energia.

🔎

Filtros de consulta

Permite selecionar estado, região, período e tipo de energia para refinar a análise.

🗺️

Mapa de calor por região

Destaca áreas com maior concentração ou crescimento, ajudando a encontrar oportunidades comerciais.

📈

Evolução anual

Mostra a evolução dos dados ao longo dos anos para comparar tendências e crescimento por localidade.

🏆

Ranking de estados

Organiza os estados com melhor desempenho, facilitando decisões estratégicas.

📄

Relatórios futuros

Estrutura preparada para futuras exportações e relatórios com base nos filtros selecionados.

Como funciona

Do dado bruto à decisão visual

1

Coleta de dados

Dados públicos e informações energéticas são levantados a partir de fontes institucionais.

2

Organização no banco

As informações são estruturadas em SQL Server para permitir consultas por filtros.

3

Processamento

As classes de controle validam filtros, consultam os dados e organizam os resultados.

4

Visualização

A dashboard em Java apresenta gráficos, indicadores, rankings e comparações.

Tecnologias e modelagem
